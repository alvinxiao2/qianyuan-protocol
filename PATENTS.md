# Patent stance

**The Qian Yuan project does not intend to file patent applications covering the designs
described in this repository, and publishes them as defensive prior art.**

- The design paper (*Toward a Portable Work Record for Agents*, v1) is deposited under
  CC BY 4.0. Its public timestamp is intended to prevent others from later obtaining
  patents over the same design.
- Source code in this organisation is licensed under Apache License 2.0, which includes
  an express patent grant (Section 3) and patent-retaliation terms.
- Contributions are accepted under the same inbound=outbound terms.

*This is a statement of the project's intent and licensing position. It is not legal advice
and does not create rights beyond those granted by the applicable licences.*
